# INF1018 - Gerador de Código com Funções

Este repositório contém o desenvolvimento do trabalho da matéria **INF1018**.

## Objetivo
O objetivo deste trabalho é desenvolver em C uma função chamada `gera_codigo`, que implementa um gerador de código (um "micro-compilador" muito simples) para uma linguagem de programação bastante simples, chamada **LBS**.
